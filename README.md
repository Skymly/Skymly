# Skymly

.NET / Roslyn. I write source generators so you don't write the glue.

**[Observables](https://github.com/Skymly/Observables)** turns .NET events and IO (HTTP, SignalR, MQTT, WebSocket, gRPC, SSE, NATS, Postgres, Redis, …) into **R3** or **System.Reactive** streams. Stable 0.2.0, ~20 NuGet packages.

[Docs](https://skymly.github.io/Observables.Docs/) · [Samples](https://github.com/Skymly/Observables.Samples) · [NuGet](https://www.nuget.org/profiles/Skym)

Also: [DesignPatterns](https://github.com/Skymly/DesignPatterns) · [GitPulse](https://github.com/Skymly/GitPulse) (Observables in a MAUI GitHub client) · [dotnet-mcp](https://github.com/Skymly/dotnet-mcp) · [MvvmAIO](https://github.com/MvvmAIO)
