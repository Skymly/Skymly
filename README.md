Ten-domain reactive Roslyn generators (events, HTTP, SignalR, MQTT, WebSocket, gRPC, SSE, NATS, Postgres, Redis) → **R3** / **System.Reactive**. Stable **0.2.0**, ~20 NuGet packages.
