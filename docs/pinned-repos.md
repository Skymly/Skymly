# Suggested profile pins (maintainer)

GitHub allows up to **six** pinned repositories. Configure under **Profile → Customize your pins**.

| # | Repository | Rationale |
|:-:|:---|:---|
| 1 | [`Skymly/Observables`](https://github.com/Skymly/Observables) | Reactive Roslyn generators — events, RestAPI, SignalR (R3 / System.Reactive) |
| 2 | [`Skymly/DesignPatterns`](https://github.com/Skymly/DesignPatterns) | Open-source design-pattern toolkit + Roslyn integration (early preview) |
| 3 | [`Skymly/Observables.Docs`](https://github.com/Skymly/Observables.Docs) | VitePress documentation (English + 简体中文) |
| 4 | [`Skymly/Observables.Samples`](https://github.com/Skymly/Observables.Samples) | Runnable Observables demos |
| 5 | [`MvvmAIO/Prism.SourceGenerators`](https://github.com/MvvmAIO/Prism.SourceGenerators) | Prism MVVM source generators (collaboration) |
| 6 | [`MvvmAIO/MvvmAIO.R3.SourceGenerators`](https://github.com/MvvmAIO/MvvmAIO.R3.SourceGenerators) | R3 MVVM generators in the MvvmAIO ecosystem |

**If you need pin #6 for docs** — Swap pin 6 for [`MvvmAIO/Prism.SourceGenerators.Docs`](https://github.com/MvvmAIO/Prism.SourceGenerators.Docs), or drop `Observables.Samples` / `Observables.Docs` to keep all three Skymly product repos pinned.

**Optional** — Pin [`Skymly/Skymly`](https://github.com/Skymly/Skymly) (this profile README) instead of one MvvmAIO repo.
