# Suggested profile pins (maintainer)

GitHub allows up to **six** pinned repositories. Configure under **Profile → Customize your pins**.

**Suggested pins (late Aug 2026):** Observables · DesignPatterns · GitPulse · dotnet-mcp · Prism.SourceGenerators · Observables.Docs.

| # | Repository | Rationale |
|:-:|:---|:---|
| 1 | [`Skymly/Observables`](https://github.com/Skymly/Observables) | Flagship — ten-domain reactive Roslyn generators (R3 / System.Reactive), stable 0.2.0 |
| 2 | [`Skymly/DesignPatterns`](https://github.com/Skymly/DesignPatterns) | Design-pattern toolkit + Roslyn — [`Skymly.DesignPatterns`](https://www.nuget.org/packages/Skymly.DesignPatterns) on NuGet |
| 3 | [`Skymly/GitPulse`](https://github.com/Skymly/GitPulse) | Living Observables showcase (.NET MAUI); featured on profile README |
| 4 | [`Skymly/dotnet-mcp`](https://github.com/Skymly/dotnet-mcp) | .NET MCP server (C#/VB/F# symbols, XAML, generator attribution, restricted edit) |
| 5 | [`MvvmAIO/Prism.SourceGenerators`](https://github.com/MvvmAIO/Prism.SourceGenerators) | Prism MVVM source generators (collaboration) |
| 6 | [`Skymly/Observables.Docs`](https://github.com/Skymly/Observables.Docs) | Public docs site for Observables (open slot) |

**Do not pin private repositories** on the public profile (visitors cannot open them).

**Do not feature pre-announce / overly early apps** on the profile README until they are ready for a public narrative.

**Optional** — Pin [`Skymly/Skymly`](https://github.com/Skymly/Skymly) (this profile README) in slot 6 instead of Docs.
