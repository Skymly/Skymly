# Suggested profile pins (maintainer)

GitHub allows up to **six** pinned repositories. Configure under **Profile → Customize your pins**.

| # | Repository | Rationale |
|:-:|:---|:---|
| 1 | [`Skymly/Observables`](https://github.com/Skymly/Observables) | Core suite — Roslyn generators for events, RestAPI, SignalR, and dual R3 / System.Reactive targets |
| 2 | [`Skymly/Observables.Docs`](https://github.com/Skymly/Observables.Docs) | VitePress documentation (English + 简体中文) |
| 3 | [`Skymly/Observables.Samples`](https://github.com/Skymly/Observables.Samples) | Runnable demos for Events and RestAPI generators |
| 4 | [`MvvmAIO/Prism.SourceGenerators`](https://github.com/MvvmAIO/Prism.SourceGenerators) | Prism-oriented MVVM source generators (collaboration) |
| 5 | [`MvvmAIO/MvvmAIO.R3.SourceGenerators`](https://github.com/MvvmAIO/MvvmAIO.R3.SourceGenerators) | R3-targeted MVVM generators in the MvvmAIO ecosystem |
| 6 | [`MvvmAIO/Prism.SourceGenerators.Docs`](https://github.com/MvvmAIO/Prism.SourceGenerators.Docs) | Docs for Prism.SourceGenerators — preferred over pinning `Skymly/Skymly` so all six slots surface product work |

**Optional swap for pin #6** — Use [`Skymly/Skymly`](https://github.com/Skymly/Skymly) instead of `Prism.SourceGenerators.Docs` if you want this profile repo visible among pins.
